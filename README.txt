# MalicarShop — prototype web

## Ouvrir le site
1. Décompressez `malicarshop_web.zip`.
2. Ouvrez `index.html` dans Chrome, Firefox ou un autre navigateur.
3. Le site fonctionne sans installation. Une connexion Internet est nécessaire pour charger les images distantes.

## Fonctionnalités de démonstration
- Présentation MalicarShop responsive mobile/ordinateur
- Recherche par marque, modèle et année
- Filtres par catégorie
- Détails des véhicules
- Favoris temporaires
- Formulaire d'ajout d'annonce dans la session navigateur

## Avant un vrai lancement
Ce prototype n'est pas relié à une base de données. Les annonces d'exemple ne sont pas vérifiées et les annonces ajoutées ne sont pas publiées publiquement. Pour le lancement réel, prévoir une base de données, authentification, stockage des photos, modération, contacts vendeurs, politique de confidentialité et hébergement.
